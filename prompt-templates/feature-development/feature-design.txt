## BRAINRASH DESIGN SYSTEM

### Core Framework & Components
- **Framework**: Tailwind CSS with custom design tokens and CSS variables
- **Component Library**: 80+ Radix UI components in `/components/ui/`
- **Component Variants**: Class Variance Authority (cva) for consistent variants
- **Utility Function**: `cn()` function for Tailwind class merging and conflict resolution

### Color System
- **Primary Colors**: HSL-based color system with CSS variables
- **Semantic Colors**: Success, warning, info, destructive with foreground variants
- **Category Colors**: 30+ brain domain-specific colors (business, knowledge, physical, etc.)
- **Flow States**: Low, medium, high, and state-specific colors
- **Accessibility**: High contrast ratios and semantic color usage

### Typography & Spacing
- **Font Family**: Inter (Google Fonts) with established scale
- **Spacing System**: 4px base unit system (4, 8, 12, 16, 20, 24, 32, 48, 64)
- **Container System**: Responsive container with 2rem padding and 1400px max-width
- **Border Radius**: CSS variable-based radius system (sm, md, lg)

### Animation & Interactions
- **Keyframes**: Custom animations for accordion, gradient, pulse, flow-pulse, float
- **Transitions**: Smooth transitions for hover states and component interactions
- **Micro-interactions**: Subtle animations for user feedback
- **Performance**: Optimized animations with CSS transforms

### Component Patterns
- **Button Variants**: default, destructive, outline, secondary, ghost, link
- **Button Sizes**: default, sm, lg, icon
- **Card Layouts**: Consistent rounded corners and subtle shadows
- **Form Elements**: Radix-based inputs with consistent styling
- **Data Tables**: TanStack Table integration with custom styling

### Responsive Design
- **Breakpoints**: Mobile-first approach with Tailwind's responsive utilities
- **Mobile Navigation**: Dedicated mobile navigation component
- **Touch Targets**: Appropriate sizing for mobile interactions
- **Viewport**: Optimized for various screen sizes and orientations
