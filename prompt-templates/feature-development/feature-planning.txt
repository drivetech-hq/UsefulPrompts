The platform includes features for course creation, AI tutoring, blockchain integration, BCI (Brain-Computer Interface) capabilities, and comprehensive analytics.

## BRAINRASH TECHNICAL CONTEXT

### Core Technologies
- **Frontend**: Next.js 15 with App Router, React 18, TypeScript 5
- **Database**: PostgreSQL with Drizzle ORM (v0.44.1)
- **Authentication**: Supabase Auth with SSR support
- **AI Integration**: OpenAI API (v5.3.0), Groq SDK
- **Blockchain**: Ethereum with Ethers.js (v6.11.1)
- **Styling**: Tailwind CSS with custom design system and Radix UI components
- **State Management**: TanStack React Query, SWR, server actions
- **Testing**: Vitest (v3.0.9), Playwright (v1.40.0), React Testing Library
- **Deployment**: Vercel with Supabase backend

### Database Schema Structure
- **Location**: `/db/schema/` with 100+ schema files
- **Key Tables**: users, courses, lessons, brain-sparks, tokens, BCI sessions
- **Patterns**: Separate dev/prod schemas, comprehensive user tracking
- **Migrations**: Drizzle Kit with PostgreSQL dialect

### Component Architecture
- **UI Components**: `/components/ui/` with 80+ Radix-based components
- **Component Library**: Button, Card, Dialog, Form, Table, Charts, etc.
- **Styling**: Class Variance Authority (cva) for component variants
- **Utilities**: `cn()` function for Tailwind class merging

### File Organization
- **App Router**: `/app/[feature]/` with page.tsx, loading.tsx, error.tsx
- **Components**: `/components/[feature]/` organized by feature
- **Actions**: `/actions/[feature]-actions.ts` for server actions
- **Types**: `/types/[feature]-types.ts` for TypeScript definitions
- **Lib**: `/lib/[feature]/` for utility functions

### Testing Infrastructure
- **Unit Tests**: Vitest with jsdom environment
- **E2E Tests**: Playwright with multiple browser support
- **Test Coverage**: V8 coverage provider with HTML reports
- **Test Organization**: `/__tests__/` and `/e2e/` directories

### Development Workflow
- **Package Manager**: Yarn (enforced)
- **Linting**: ESLint with Next.js and Tailwind rules
- **Formatting**: Prettier with custom configuration
- **Type Checking**: TypeScript strict mode enabled
- **Database**: Drizzle Kit for schema management

Remember to consider BrainRash's existing architecture, user experience patterns, and technical standards when planning your feature. Follow the established patterns for database schemas, component structure, and testing organization.
